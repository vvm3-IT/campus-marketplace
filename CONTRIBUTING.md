# Contributing

1. Accept the repository invitation from GitHub notifications.
2. Open your linked assignment in TEAM_TASKS.md.
3. Read the original source yourself. Add a finding and decision in your own words to docs/index.md.
4. Use your own GitHub account to commit. Include your issue number, for example `Explain listing condition decision (#1)`.
5. Link the commit in your assignment issue and explain what changed and why. Claim only checks you performed.
6. Keep hypotheses labeled until actual research supports them. Do not invent interviews, feedback, or completed work.

GitHub Pages publishes docs/ from main automatically. Changes to docs/index.md update the shared record. Do not create separate research records or repositories for this team project.

Peer review is not performed by the setup assistant; follow the course's review process separately.
